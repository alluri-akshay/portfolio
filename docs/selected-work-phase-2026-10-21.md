# Selected Work refinement

Implemented 21 October 2026 for a compact, recruiter-oriented overview.

- One lead Career Nexus card followed by two supporting cards in a two-column desktop layout; all stack on mobile.
- Short section heading and introduction; removed the repeated project index and standalone technology strip between hero and work.
- Each card presents category, title, one-sentence summary, contribution, up to three technologies, case-study link, and available demo/source links.
- Removed the oversized chapter numbers, repeated capability checklists, persistent progress accents, and heavy browser frames from the overview. Case studies retain their fuller content.
- Existing screenshots remain unchanged. Auto Auth uses a compact, explicitly labeled workflow illustration derived from existing documented capabilities.
- Preview response is limited to 1.8-degree pointer tilt and 3px lift, with a once-only card entrance, stable controls, keyboard focus feedback, and the existing site motion preference.
- Scoped styles keep this layout separate from case-study and supporting-section presentation.

No new project evidence or outcome claims were added. No build or test suite was run; the owner will review the UI.
